Create a **premium, modern SaaS Hub website** that serves as the central digital ecosystem for all of my SaaS products. The website should feel like a polished **SaaS product ecosystem / mini app marketplace**, not a simple collection of links.

The architecture should remain simple with **2 main pages**, while individual SaaS products use a **beautiful detail overlay/modal** instead of separate detail pages.

---

# 1. Overall Concept

The platform should communicate:

> **One Hub. All My SaaS Products.**

Users should be able to:

* Discover my SaaS products
* Learn what each product does
* Browse products by category
* Search for a specific product
* See newly launched and featured products
* Open any SaaS directly
* Discover products that are coming soon

The website should be designed so that adding new SaaS products in the future is extremely easy.

---

# 2. Page Structure

Create exactly **2 primary pages**:

### Page 1 — Home

Purpose: Branding, introduction, promotion, and product discovery.

### Page 2 — Apps

Purpose: Complete SaaS directory where users can browse and access all products.

Individual SaaS information should appear in a **detail overlay/modal** when a user clicks a product rather than creating a separate page for every SaaS.

---

Left:

* SaaS Hub logo/brand name

* Home

* Work perfectly on mobile
* Collapse into a professional mobile menu

The active page should have a clear but elegant visual highlight.

The most important goal is:

**Users should understand what the SaaS Hub is within 5 seconds and reach any SaaS product within 2–3 clicks.**

The homepage should focus on:
**Brand → Discovery → Promotion**

The Apps page should focus on:
**Search → Filter → Discover → Open**

**Understand → Decide → Launch**
